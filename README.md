# Sri Arunambiga Trust — mobile-ready website

Responsive static website for Sri Arunambiga Trust in Tiruvannamalai. This public version includes the trust's devotional artwork and landscape photography. Photos showing identifiable residents and visitors are not included.

## Preview locally

Run `node .\preview-server.mjs` in PowerShell and open <http://127.0.0.1:4174>.

## Gallery

The gallery currently presents the trust's surroundings and devotional imagery. Visitors can share photos with the trust through WhatsApp. A Google-account-restricted admin uploader is not configured in this static version.

## Hosting

The `.github/workflows/pages.yml` workflow publishes this folder to GitHub Pages after it is pushed to the `main` branch. In GitHub repository Settings → Pages, choose **GitHub Actions** as the deployment source if Pages has not been enabled yet.
